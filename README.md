# Mercurius
Warframe helper bot! Currently contains mostly warframe.market related functions, but more commands will be added soon.

## Using commands
Mercurius does not use any privileged gateway intents (Message Content, Server Members or Presence), so none need to be enabled in the Discord developer portal.

Because of this, Discord only lets the bot read a server message when it mentions the bot. In servers, use slash commands or mention the bot as the prefix, e.g. `@Mercurius help`. In DMs the `--` prefix (or no prefix at all) still works.
